# Personal-BookManagement
 A personal space for readers — to log their books, reflect on their habits, and rediscover their favorite authors

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

## Project Structure

```text
.
├── apps/
│   ├── frontend/
│   └── backend/
├── package.json
├── pnpm-workspace.yaml
└── README.md
```

## Getting Started

### Install dependencies

```bash
pnpm install
```

### Run both frontend and backend

```bash
pnpm dev
```

### Run frontend only

```bash
pnpm dev:frontend
```

### Run backend only

```bash
pnpm dev:backend
```
